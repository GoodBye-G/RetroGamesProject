# 🕹️ Retro Arcade — Telegram Mini App

Ретро-аркада из 6 браузерных игр (по 2 от каждого участника), которая будет открываться внутри Telegram.

Полный план — [PROJECT_PLAN.md](PROJECT_PLAN.md). Правила работы с ветками и папками — [CONTRIBUTING.md](CONTRIBUTING.md).

## Структура

```text
webapp/
  games/
    si/          2 игры Участника 1 — СИ
    sv/          2 игры Участника 2 — СВ
    sha/         2 игры Участника 3 — ША
bot_cpp/         Telegram-бот на C++ (позже)
presentation/    Материалы к защите (позже)
```

## Порядок работы

1. **Сейчас:** каждый делает свои 2 игры в своей папке.
2. **Потом:** главное меню, общий дизайн и Telegram-бот.
