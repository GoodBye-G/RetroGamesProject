# Шаблон игры

Готовая заготовка с обязательными частями: Telegram Web App, общая тема, кнопка «← В меню», счёт и рекорд, оверлей старта, клавиатура + экранные кнопки.

Чтобы начать свою игру:

1. Скопируйте `index.html`, `style.css`, `game.js` в папку своей игры (в рабочих местах участников это уже сделано).
2. В `game.js` поменяйте `GAME_ID` и замените заглушку на свою логику.
3. В `index.html` поменяйте `<title>` и заголовок оверлея.

Правила — в [CONTRIBUTING.md](../../../CONTRIBUTING.md).
