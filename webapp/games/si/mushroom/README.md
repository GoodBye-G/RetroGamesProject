# Месть грибов

Игра участника СИ. Перевёрнутый платформер: ты — грибок, а враги — самоуверенные герои-прыгуны.
Теперь твоя очередь прыгать им на головы.

Чистый HTML5 Canvas + JavaScript, без библиотек и сборки.

## Как запустить

Из корня репозитория:

```bash
python -m http.server 8765 --directory webapp
```

Открыть в браузере: <http://localhost:8765/games/si/mushroom/>

(Двойной клик по `index.html` тоже работает, но лучше через сервер — так браузер точно загрузит музыку.)

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Бег | ← → или A D | кнопки ◀ ▶ |
| Прыжок | Пробел, W, ↑ (или Z) | кнопка ПРЫЖОК |
| Пауза | P или Esc | кнопка II вверху |
| Громкость | кнопка ♪ вверху | кнопка ♪ вверху |

* Держишь прыжок дольше — грибок прыгает выше.
* Можно прыгнуть чуть позже, чем сошёл с края (койот-тайм).
* Экранные кнопки появляются сами на устройствах с сенсорным экраном. Можно жать бег и прыжок одновременно.

## Правила

* Прыгнул на героя сверху — герой сплющен, грибок отскакивает, очки. Несколько героев подряд без приземления — очки удваиваются.
* Задел героя сбоку, наступил на шипы или упал в яму — минус жизнь. Жизней 3, максимум 5.
* Бонус-блок (с листиком): ударь снизу головой — выпадет монетка или сердечко, блок станет пустым.
* Треснувший кирпич разбивается ударом снизу.
* Сердечко из блока выпрыгивает и скатывается вниз, где его можно подобрать. Даёт жизнь, а если жизней уже 5 — 500 очков.
* **Мега Альфа.** Из некоторых бонус-блоков выпадает маленькая красная сфера в белую точку. Она катится и отскакивает
  от стен — догони её! Грибок превращается в огромного злого мухомора (втрое больше, красная шляпка, красные глаза) на 7 секунд:
  * проламывает **все блоки**, через которые проходит: стены, ящики, кирпичи, колонны, потолок, платформы, шипы
    (землю под ногами не трогает, бонус-блоки сначала отдают содержимое);
  * сносит героев одним касанием (+200);
  * если зацепит шипы или героя сверху, не теряет жизнь, а просто сдувается обратно;
  * за 2 секунды до конца начинает мигать.
  Сферы спрятаны: луг — блок справа в первом ряду блоков; пещера — средний блок в самом начале;
  крепость — два блока (около 53-й и 152-й клетки).
* В конце уровня флаг. Чем выше на него запрыгнул — тем больше бонус.
* Рекорд сохраняется в браузере (`localStorage`).

## Панель сверху

Слева в красной рамке **HP**: красные сердечки — жизни, которые есть, тёмные — потерянные, рядом число `3/5`.
Когда жизнь теряется или прибавляется, рамка вспыхивает. С читом бессмертия там `♥ ∞`.
В жёлтой рамке `◎ 20` — собранные монетки. Справа счёт, уровень (на узком экране телефона название уровня скрыто), кнопки ♪ и II.

## Читы (кнопки на паузе)

Поставь игру на паузу (P, Esc или кнопка II) — под «Продолжить» есть кнопки читов и выбора уровня.
Зелёная кнопка — чит включён, повторное нажатие выключает. Если в забеге включали читы, рекорд не сохраняется.

| Кнопка | Что делает |
|---|---|
| Бессмертие | герои, шипы и ямы не отнимают жизни (вкл/выкл) |
| Вечная Альфа | Мега Альфа навсегда (вкл/выкл) |
| Луна | лунная гравитация: прыжки в 2,5 раза выше (вкл/выкл) |
| Турбо | бег в 1,6 раза быстрее (вкл/выкл) |
| Рентген | видны невидимые блоки и тайники-пасхалки (вкл/выкл) |
| Мега Альфа 7с | стать Мега Альфой на 7 секунд |
| +100 монет | +100 монеток |
| Полные HP | жизни до максимума (5) |
| Убрать героев | убрать всех героев с текущего уровня |
| Выключить всё | выключить все читы |
| 1 Луг, 2 Пещера, 3 Крепость | сразу перейти на уровень (счёт и жизни сохраняются; текущий уровень обведён) |
| ☠ ??? | секретный уровень «Кошмар» |

### Секретный уровень «Кошмар»

Открывается красной кнопкой **☠ ???** на паузе (в скобках — сколько раз ты там уже умирал).
Внимание: страшные звуки, кровь, вспышки, скримеры. Вспышки не чаще 3 раз в секунду.

Сделан по исследованию пиксельных хорроров (Sonic.exe, FAITH, Ib, Undertale, Super Meat Boy, Celeste и др.):
страх — это контраст и нарушенное доверие; сложность — это быстрый рестарт и честная, видимая опасность.

**Тихое начало.** Обычный луг, твоя музыка, доброе солнышко, которое следит глазами. Что-то не так:
на миг у горизонта мелькает тёмный силуэт, слева за кадром слышны шаги (а там никого), далёкий шёпот.
Ближе к чекпоинту музыка замедляется и затихает почти до тишины.

**Превращение** на секретном чекпоинте: скрежет пластинки, помехи, мир краснеет, вкладка браузера мигает
«ОНО ПРОСНУЛОСЬ», твоя музыка играет **задом наперёд**, солнце с криком сходит с неба, засасывает героев.
Повсюду проявляются трупы, кровь, кресты, глаза в темноте, надписи кровью. Если ты здесь не впервые —
«ОПЯТЬ ТЫ. 5-Й РАЗ», и на названии игры в меню появляется трещина.

**Погоня из 4 секций.** Монстр — тёмный силуэт с горящими глазами (целиком его видно только при поимке):
1. **Ввод** — ямы, шипы, осыпающиеся мосты. Монстр летит на 85% скорости грибка.
2. **Развитие** — ямы по 4 клетки, островки в 1–2 клетки, мосты без ровного выхода, герои-прыгуны прямо на пути. 90%.
3. **Поворот** — подъём по ступеням (монстр нагоняет), **развилка** (верх — узкие островки с монетками,
   низ — ямы и шипы, обе дороги ведут вперёд), «пустая» пауза: монстр замолкает на 3 секунды — и бросается;
   **погоня на скорости**: «ГОНИ!» — грибок сам несётся вперёд, огромное солнце летит рядом на полэкрана,
   ветер свистит, прыгать через ямы на бегу. 95%.
4. **Итог** — игра «вылетает»: звук обрывается щелчком, окно ошибки «sun.chr повреждён», вкладка «не отвечает»…
   окно стекает, из-под него лезет монстр. **Финальный рывок**: мир в два цвета (1-bit), монстр быстрее грибка (103%),
   музыка погони вдвое быстрее. Потом флаг, «УРОВЕНЬ ПРОЙДЕН!»… буквы сползают — «ТЫ ПРАВДА ДУМАЛ?» — и ещё 5 секунд погони.
5. **Луна и замок.** На настоящем флаге солнце отстаёт… но с неба спускается жуткая луна (бледная, пустые глазницы,
   зубастая ухмылка), забирает флаг — «ЭТО МОЙ ФЛАГ» — и улетает. За флагом стоит **замок** (свой, кирпичный,
   с двумя башнями и красными окнами; из тёмной двери кто-то смотрит). Грибок входит в дверь.
6. **Башня.** Внутри луна **пробивает стену** снизу, летят кирпичи — «ХРУМ!» — **откусывает кусок замка** и уходит вниз.
   Дальше она поднимается снизу и съедает всё, а ты карабкаешься вверх: факелы, окна с ночным небом, качающиеся цепи,
   трупы на площадках, 4 чекпоинта по высоте.
7. **Бой под рэп.** На вершине — сцена: **рэпер-скелет** в красной кепке, с золотой цепью и микрофоном, по бокам колонки.
   Он читает свою страшную песню: тяжёлый бит, «бормотание»-писк на каждый слог, строчки — субтитрами внизу.
   Луна в ритм бита высовывается из ямы в полу (прыгай ей на голову!) и прячется. **Три фазы — каждая страшнее:**
   * **Фаза 1** — бледная луна, пустые глазницы. Два такта торчит, такт прячется, на 4-й с рыком (и «!») **выпрыгивает** из ямы.
   * **Фаза 2** — «ЛУНА ТРЕСКАЕТСЯ»: трещины, чёрные слёзы. Прыгает чаще и выше, при приземлении пускает **ударные волны**
     по полу в обе стороны, плюётся веером осколков, с потолка падают сосульки (сначала мигает метка, куда упадут).
   * **Фаза 3** — «НАСТОЯЩЕЕ ЛИЦО»: красные глазницы, рваная пасть, вены. Прыжки почти каждый такт, осколки и дождь
     с потолка на **каждую долю**. Бит после каждого удара ускоряется.
   Рэпер тоже меняется: красная аура, горящие глаза, треснувший череп, отвисшая челюсть — и в каждой фазе свой куплет.
   Три удара — луна разлетается, скелет говорит «…ЛАДНО. ТЫ ПОБЕДИЛ.» и рассыпается на кости.

**Внезапные ужасы по дороге:**
* **Рука из земли** (клетка `G`) — без предупреждения хватает грибка за ногу: он застывает на секунду,
  над ним «!», визг. Монстр в это время не спешит — смакует.
* **Трупы шевелятся** — дёргаются и тянут руки вверх.
* **Солнце звереет по секциям** («ОНО ЗЛИТСЯ», «ОНО ГОЛОДНО» — крик, тряска): сначала улыбка и кровь из ушей,
  потом кровавые слёзы и красные лучи, потом трещины и третий глаз, в конце — пустые глаза, пасть до ушей и чёрно-красные лучи.
* **Солнце глотает трупы**: по дороге они отрываются от земли и, кружась, улетают ему в рот. А в третьей секции
  оно **швыряет трупы** вперёд дугой — пасть открывается заранее, на земле мигает красный крест, куда упадёт.

**Смерть — как в Super Meat Boy.** Жизней нет, есть счётчик смертей (сверху и в финале). Поймали, упал в яму,
наступил на шипы или задел героя — мгновенный рестарт **с начала текущей секции**: карта восстанавливается,
монстр на полэкрана позади. Почти никакой неуязвимости — 0,5 секунды.

**Перед рывком монстр предупреждает** (за 0,4 с): вдох, вспышка глаз, «вжух» — успей отреагировать.

**Звук:** твой трек в кошмаре звучит **один раз** (на превращении — задом наперёд, в погоне — «зажёванной кассетой»),
а когда он закончится, начинается **синтезированная страшная музыка** в духе пиксельных хорроров: расстроенная
музыкальная шкатулка на тритонах, низкий бас, далёкий вой; в погоне и в бою она быстрее. Плюс гул, бесконечно
падающий тон Шепарда, сирена, сердце и дыхание чаще, когда монстр ближе. Перед пиками — тишина.

**Скримеры изнашиваются:** три разных варианта (лицо, глаз во весь экран с глитчем, тишина и «ПОЙМАЛ»)
со случайной задержкой; после 5 смертей подряд в одной секции — только темнота и «ЕЩЁ РАЗ?».

**Четвёртая стена (всё безопасно и обратимо):** заголовок и иконка вкладки меняются в погоне;
если уйти на другую вкладку и вернуться — «НЕ УХОДИ. Я ЖДАЛ.»; игра помнит, сколько раз ты приходил и умирал;
поздно вечером финал скажет, который час и что пора спать; на обычном Лугу солнышко раз в много минут на миг
показывает не то лицо. Ничего не удаляется, камера и уведомления не используются.

**Декорации меняются, пока на них не смотришь:** трупы за краем экрана переворачиваются.

**Декор кошмара:** кровь на шипах (стекает и капает), мёртвые деревья с вороном, который поворачивает голову за тобой,
кости, черепа на кольях, свечи, туман по низу экрана; в башне — портреты, чьи глаза следят за грибком, кровь на стенах,
паутина, свечи и кости на площадках.

Особые клетки кошмара: `K` — секретный чекпоинт, `S` — начало секции, `J` — герой внутри погони, `G` — рука из земли,
`Q` — «пустая» пауза, `Z` — фальшивый вылет, `f` — ложный флаг. Скорость монстра по секциям — `sectionSpeed`,
погоня на скорости — `speedZone`. `Y` — дверь замка за флагом. Башня луны — `window.MUSHROOM_TOWER`: `T` — чекпоинт, `W` — центр арены боя,
`R` — рэпер-скелет, `O` — колонки, `t` — факел, `w` — окно, `k` — цепь, `u` — мёртвое дерево с вороном, `b` — кости, `n` — череп на колу, `c` — свечи,
`q` — паутина, `p` — портрет, `z` — кровь на стене, `crumbleDelay` — сколько держатся осыпающиеся площадки.

Карта уровня — `window.MUSHROOM_NIGHTMARE` в `levels.js`, её можно перерисовать, как обычные уровни
(`nightmare: true` включает весь этот сценарий, `K` — место превращения).

## Уровни: как нарисовать свой

Уровни лежат в `levels.js`. Каждый уровень — текстовая карта: одна строка = один ряд клеток 16×16 пикселей,
один символ = одна клетка. Высота обычно 13 строк (у крепости 14: верхняя строка — над крышей), длина любая. Строки не обязаны быть одной длины:
короткие дополняются пустотой.

### Легенда

| Символ | Что это |
|---|---|
| `.` | пусто (воздух) |
| `#` | земля (на лугу верхний слой сам рисуется с травой) |
| `B` | каменный кирпич |
| `C` | треснувший кирпич — разбивается ударом снизу |
| `X` | ящик |
| `?` | бонус-блок с монеткой |
| `H` | бонус-блок с сердечком |
| `M` | бонус-блок со сферой-мухомором (превращает в «Мега Альфу») |
| `=` | деревянная платформа — снизу можно пройти насквозь, сверху стоять |
| `^` | шипы |
| `I` | колонна (верхушка рисуется сама) |
| `o` | монетка в воздухе |
| `h` | сердечко в воздухе |
| `m` | сфера-мухомор в воздухе |
| `P` | старт грибка |
| `e` | герой-бегун |
| `j` | герой-прыгун (иногда подпрыгивает) |
| `F` | флаг — ставь на клетку прямо над землёй, шест вырастет вверх на 6 клеток |
| `!` | невидимый блок — не виден и не мешает, пока не ударишь его головой снизу; тогда появляется (с монеткой), и на нём можно стоять |
| `$` | тайник-пасхалка — невидимая клетка: коснулся — «Секрет найден!» и +1000 очков |
| `K` | только в кошмаре: секретный чекпоинт, где начинается погоня |

Советы:

* Нижние две строки обычно земля `#` (или `B` в крепости). Яма — просто пустые клетки в земле.
* Героев ставь на строку прямо над землёй: герой высотой почти 3 клетки, над ним должно быть свободно.
* Грибок прыгает примерно на 4 клетки вверх и на 4–5 клеток в длину. Ямы шире 3 клеток лучше не делать.
* Бонус-блоки удобно ставить на 4 клетки выше земли.

### Пасхалки (спойлер!)

В каждом уровне спрятан тайник `$`. Сколько найдено, видно на паузе и на финальном экране («Секреты: 2 из 3»).

1. **Луг — «Подпись автора в небе».** Сразу за двумя шипами в воздухе висит невидимый блок. Ударь его снизу,
   залезь на него и запрыгни на платформу в небе: там монетки складываются в буквы «СИ».
2. **Пещера — «Грибная заначка».** Около 90-й клетки два невидимых блока лесенкой: один низко, второй выше и правее.
   Найди оба, поднимись по ним на платформу под потолком — там сердечко и монетки.
3. **Крепость — «Крыша крепости».** В начале уровня высокая колонна. С неё на два шага правее — невидимый блок,
   его можно нащупать головой, стоя на бонус-блоках. Встань на него и разбей два треснувших кирпича в потолке —
   выйдешь на крышу. По крыше можно добежать до самого флага, не встречая героев.

Свой тайник: поставь `$` в труднодоступное место и впиши название в `secret` у уровня.

### Настройки уровня

```js
{
  name: 'Луг',        // название, показывается при старте уровня
  bg: 'meadow',       // фон: 'meadow' (луг) или 'cave' (пещера)
  tint: 0,            // затемнение фона: 0 — нет, 0.5 — сильно
  grass: true,        // трава на верхнем слое земли
  enemySpeed: 28,     // скорость героев
  jumpEvery: 2.2,     // как часто прыгают герои «j», в секундах
  secret: 'Подпись автора в небе',   // название тайника «$» на этом уровне
  map: [ ... ]
}
```

Новый уровень — просто ещё один такой объект в конце списка `window.MUSHROOM_LEVELS`.

## Звук

Все звуки (прыжок, монетка, удар, урон, проигрыш, флаг) синтезируются прямо в коде через Web Audio API — файлов не нужно.
Звук включается после первого нажатия клавиши или касания (так требуют браузеры).

**Фоновая музыка** — файл `assets/music.mp3` (трек «почему нет игры, где ты типо гриб»). Играет по кругу,
пока идёт игра. На паузе и на экранах проигрыша и победы молчит.
«Играть» / «Ещё раз» запускают трек с начала.

**Громкость.** Кнопка ♪ вверху открывает панель с двумя ползунками: «Музыка» и «Звуки» (эффекты).
Ползунок в ноль — этот звук выключен. Игра запоминает громкость в браузере.

Поменять трек — положи другой mp3 с тем же именем. Имя файла и громкость по умолчанию — вверху `game.js`:

```js
var MUSIC_FILE = 'assets/music.mp3';
var MUSIC_VOLUME = 45;     // музыка по умолчанию, 0–100
var SFX_VOLUME = 100;      // звуки по умолчанию, 0–100
```

Если файла нет, игра просто идёт без музыки.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | страница игры |
| `style.css` | стили (только этой игры) |
| `game.js` | движок: физика, враги, блоки, звук, экраны; сфера и красный лист «Мега Альфы» рисуются прямо в коде |
| `levels.js` | карты уровней |
| `assets/` | картинки и фоновая музыка `music.mp3` |

Для проверки уровней в консоли браузера есть `mushroomDebug`: например `mushroomDebug.level(2)` — сразу третий уровень, `mushroomDebug.mega()` — сразу стать Мега Альфой, `mushroomDebug.nightmare()` — кошмар.
