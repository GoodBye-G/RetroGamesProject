# bot_cpp — Telegram-бот на C++

Владелец: **Участник 1**. Разработка — в ветке `feature/bot`.

Что будет здесь:

* `CMakeLists.txt` — сборка;
* `main.cpp` — команда `/start` и Inline-кнопка `WebAppInfo`, открывающая меню с GitHub Pages;
* `include/` — заголовки и сторонние библиотеки (tgbot-cpp или аналог).

Токен бота читается из переменной окружения `BOT_TOKEN`, адрес веб-части — из `WEBAPP_URL`. Ни то, ни другое в репозиторий не коммитится (см. `.gitignore`).
